# Privacy Policy

Effective date: September 1, 2026

SIGA Meal Scheduler runs locally in the browser on SIGA schedule pages. It
reads the page only to identify meal days that have not been selected and to
activate the same controls a user can select manually.

The extension does not collect, store, sell, or transmit personal information,
schedule information, account credentials, browsing history, or analytics. It
does not contact a developer-operated server or any third party.

If this behavior changes, this policy and the Chrome Web Store privacy
disclosures will be updated before that version is released.

For privacy questions, open an issue at
https://github.com/jonibatista/siga-meal-scheduler/issues.
