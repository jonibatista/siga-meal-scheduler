# Chrome Web Store listing checklist

Use the following listing copy and complete the remaining dashboard fields
before submitting the extension.

## Single purpose

Help SIGA users schedule all currently unchecked meal days from the SIGA
schedule calendar.

## Short description

Schedule unchecked school-meal days on the SIGA calendar in one action.

## Privacy-practices declaration

The extension does not collect, transmit, or sell user data. It runs locally
on the SIGA schedule page to automate selections initiated by the user.

## Dashboard tasks

- Upload the packaged ZIP and the 128px extension icon.
- Add accurate screenshots captured from the current SIGA interface.
- Set the category and distribution countries.
- Link the published `PRIVACY.md` from the project's public repository.
- Complete the Chrome Web Store privacy fields using the declaration above.
- Verify the extension with a real SIGA account before submitting.
